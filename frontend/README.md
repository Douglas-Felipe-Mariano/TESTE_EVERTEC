## Como Executar

### Pré-requisitos
- Node.js (versão 18 ou superior)
- npm 

### Instalação e Execução

1. Navegue até a pasta do frontend:
```bash
cd frontend
```
Instale as dependencias
```bash
npm install
```
Inicia o projeto
```bash
npm start
```

A aplicação estará disponível em: http://localhost:3000
